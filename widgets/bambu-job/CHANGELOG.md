# Changelog

What changed for the person using this widget, version by version. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); the newest version is first, and the
entry of the version being published is what the Fremkit admin shows before an update.

## 1.0.2 — 2026-09-18

### Changed
- Reads the theme's colours, fonts and text scale.
- Called "Bambu print" rather than "Bambu job": the id stays `bambu-job`, which keys every
  placed tile, but the name is what a person reads.

## 1.0.1 — 2026-09-18

### Changed
- The description names the AMS panel and the chamber camera, which "the printer's current
  job" left out.

## 1.0.0 — 2026-09-18

### Added
- First release on the registry. A Bambu Lab printer's current job: progress, layer,
  temperatures and the time left, with an optional AMS panel and chamber camera.
