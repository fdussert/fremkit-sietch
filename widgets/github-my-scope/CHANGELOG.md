# Changelog

## 1.1.0 — 2026-10-19

### Changed
- Orders repositories by your own recent GitHub activity feed, while retaining notifications, review requests, and your pull requests as the source of rows. GitHub's activity feed can lag.

## 1.0.0 — 2026-10-18

### Added
- Shows repositories with the newest activity in notifications, review requests, and your pull requests.
- Lets you choose 3–10 repositories and open a listed repository in the browser.
- Clarifies that the list does not represent all GitHub activity.
