# Changelog

What changed for the person using this widget, version by version. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); the newest version is first, and the
entry of the version being published is what the Fremkit admin shows before an update.

## 1.0.0 — 2026-10-17

### Added
- First release on the registry. The app, title, artist and album of whatever the Mac is playing,
  its cover, and previous / play-pause / next controls that work whichever player owns the
  session. Needs a Fremkit with the `now-playing` channel: it is not in a release yet, so the
  tile stays empty until one ships.
