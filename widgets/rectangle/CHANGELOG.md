## 1.2.2 — 2026-10-21

### Changed
- The Fill screen button shows a filled inner square (▣) instead of a hollow outline (□).

## 1.2.1 — 2026-10-21

### Changed
- Prefer a taller, narrower tile by default (10×8 instead of 12×6) so the four action buttons
  get real touch height.

## 1.2.0 — 2026-10-21

### Changed
- Track the focused window automatically: the target refreshes on its own instead of needing a
  manual Refresh button, and the actions arm themselves as soon as a safe window is frontmost.

## 1.1.0 — 2026-10-19

### Changed
- Use macOS's built-in window management instead of the third-party Rectangle app.
- Confirm the active target window before enabling an action, then verify the resulting geometry.

## 1.0.0 — 2026-10-18

### Added
- Four large touch buttons for the active window: left half, right half, fill screen, and next display.
